# Archive

Retired content kept for reference. Jekyll ignores underscore-prefixed
directories that are not collections, so nothing here is built or published.

- `posts/`, `drafts/` — former blog posts (`_posts/`, `_drafts/`)
- `projects/` — former projects (`_portfolio/`)
- `pages/` — the `/projects/` and `/posts/` listing pages
- `publications/` — the old per-paper publication page

To restore something, move it back to its original directory.
